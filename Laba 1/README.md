# Лабораторная работа №1: Введение в Java (Hello World, простые числа, палиндромы)

## Описание работы

В рамках первой лабораторной работы выполняются три задачи, направленные на знакомство с основами языка Java: компиляция, запуск программ, работа с методами, циклами, строками и условиями.

### Задание 1. Hello World
Программа выводит на экран стандартное приветствие `"Hello World"`. Это базовый пример для проверки установки JDK и настройки окружения.

### Задание 2. Простые числа (Primes.java)
Программа находит и выводит **все простые числа** в диапазоне от 2 до 100.  
- Реализован метод `isPrime(int n)`, проверяющий, является ли число простым.  
- В методе `main` организован цикл по числам от 2 до 100 с вызовом `isPrime()` и выводом подходящих чисел.

### Задание 3. Палиндромы (Palindrome.java)
Программа проверяет, является ли переданная через аргументы командной строки строка **палиндромом** (читается одинаково слева направо и справа налево).  
- Реализован метод `reverseString(String s)` — переворачивает строку.  
- Реализован метод `isPalindrome(String s)` — сравнивает исходную строку с перевёрнутой.  
- В `main` программа принимает несколько аргументов и для каждого выводит результат.
