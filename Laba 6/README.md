# Лабораторная работа №6: Коллекции и Дженерики (Вариант 5)

## Описание работы

В лабораторной работе изучаются коллекции в Java — классы и интерфейсы для хранения и управления группами объектов. Реализована программа для учета продаж в магазине с использованием `HashMap` для хранения пар "товар — количество продаж". Также реализован обобщенный класс `Stack<T>` для работы со стеком.

## Коллекции в Java

Основные интерфейсы коллекций:
- **`Collection`** — базовый интерфейс
- **`List`** — упорядоченная коллекция с дубликатами (ArrayList, LinkedList)
- **`Set`** — неупорядоченная коллекция без дубликатов (HashSet, TreeSet)
- **`Map`** — отображение ключ-значение (HashMap, TreeMap)

## Дженерики (Generics)

Дженерики позволяют создавать обобщённые классы и методы, работающие с различными типами данных. Компилятор проверяет типы на этапе компиляции, что повышает безопасность.

```java
List<Integer> numbers = new ArrayList<>();  // список только для Integer
Stack<String> stack = new Stack<>();        // стек только для String
