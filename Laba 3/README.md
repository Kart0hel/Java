# Лабораторная работа №3: Хэш-таблица

## Описание работы

Реализована собственная хэш-таблица с использованием метода цепочек (chaining) для разрешения коллизий. Хэш-таблица хранит пары «ключ-значение» и поддерживает операции добавления, поиска и удаления.

## Как работает хэш-таблица

Хэш-таблица — это структура данных, которая использует хэш-функцию для преобразования ключа в индекс массива. По этому индексу хранится значение.

### Метод цепочек (chaining)

Когда два разных ключа получают одинаковый индекс (это называется коллизией), они не перезаписывают друг друга, а добавляются в связный список (LinkedList) по этому индексу.

**Пример:** ключи "banana" и "pear" попали в индекс 2
