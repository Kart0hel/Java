# Лабораторная работа №4: Исключения

## Описание работы

В лабораторной работе реализована обработка исключений в Java. Созданы собственные классы исключений и программа, демонстрирующая их использование.

## Что такое исключения

Исключения — это механизм обработки ошибок во время выполнения программы. Они позволяют изолировать ошибочные ситуации и обрабатывать их в специальных блоках кода, делая программу более надёжной.

## Структура обработки исключений

```java
try {
    // Код, который может вызвать исключение
} catch (ТипИсключения e) {
    // Обработка исключения
} finally {
    // Код, который выполняется всегда (опционально)
}
